# UT-Group
UT-Group is a dataset for GAR based on the publicly available UT-Data individual behavior dataset


## Dataset Download

The raw sensor recordings are available from the GitHub Release:

- [UT-Group Dataset v1.0.0](https://github.com/abc/UT-Group/releases/tag/v1.0.0)

The release contains:

- `smartphoneatpocket.csv`
- `smartphoneatwrist.csv`
